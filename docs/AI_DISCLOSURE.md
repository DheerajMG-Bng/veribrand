## Product AI

On a cache miss with AI enabled, the server sends draft text, channel, compact knowledge text and rule summaries to https://api.groq.com/openai/v1/chat/completions using HTTPX. Keys stay server-side; .env is ignored and untracked. The UI warns that drafts go to Groq and to avoid confidential content. AI proposes findings and wording; human decisions create versions and drive approval. Simulated roles are not real authentication.

Configured chain: openai/gpt-oss-120b, then openai/gpt-oss-20b, then qwen/qwen3.8-27b, then deterministic-only results. Both GPT-OSS models appeared in the original live run. The third model is configured but has not been independently verified live; mocks establish code-path behavior, not provider availability.

The validator checks literal quotes and code existence, caps unsupported findings and revalidates replacement phrases. A real code is not proof that every AI explanation is correct. Confidence is model output, not calibrated correctness. Unverified findings have no acceptable automatic replacement. Edited versions must be reviewed again before submission.

The original raw AI run had one false positive on sample 2 and is retained alongside its corrected replay. These figures are not general accuracy, population precision or independent evaluation.
